## Step 2: Apne Rules Pehle Codify Karo

*(**codify** = kisi cheez ko likhit, formal rule ke roop me tay karna — jaise rules ko ek document me define kar dena)*

Assignment me sirf itna likha hai: dimensions + weight dekh kar best box recommend karo. Baaki details (safety margin, multi-product packing, cost tie-break) **nahi** diye hain — Gemini ne jo 4 rules diye hain wo ek reasonable interpretation hai, tumhe unhe apna decision bana kar likhna hai, na ki company ka mandatory rule maan lena.

Suggested rules (likh lo README/AI_USAGE me "my assumptions" section me):
1. Product dimensions + fixed safety margin (e.g. 2cm) ≤ box internal dimensions
2. Total order weight ≤ box max_weight
3. Multiple eligible boxes me se — **least wasted volume** wala chuno
4. Tie hone par — **cheapest cost** wala chuno
5. Agar koi box fit na ho → "No suitable box found" response do

## Step 3: Models Banao (`boxes/models.py`)

```python
from django.db import models

class Product(models.Model):
    name = models.CharField(max_length=200)
    length = models.FloatField()   # cm
    width = models.FloatField()
    height = models.FloatField()
    weight = models.FloatField()   # kg
    is_fragile = models.BooleanField(default=False)

class Box(models.Model):
    name = models.CharField(max_length=200)
    internal_length = models.FloatField()
    internal_width = models.FloatField()
    internal_height = models.FloatField()
    max_weight = models.FloatField()
    cost = models.DecimalField(max_digits=8, decimal_places=2)

class Order(models.Model):
    created_at = models.DateTimeField(auto_now_add=True)

class OrderItem(models.Model):
    order = models.ForeignKey(Order, related_name="items", on_delete=models.CASCADE)
    product = models.ForeignKey(Product, on_delete=models.CASCADE)
    quantity = models.PositiveIntegerField(default=1)
```

## Step 4: Core Algorithm (`boxes/services.py`)

Simple, explainable logic — rotation-wise true 3D bin packing complex hota hai, isliye sorted-dimensions trick use karo (interview assignment ke liye kaafi hai):

```python
SAFETY_MARGIN_CM = 2

def find_best_box(total_length, total_width, total_height, total_weight, boxes):
    product_dims = sorted([
        total_length + SAFETY_MARGIN_CM,
        total_width + SAFETY_MARGIN_CM,
        total_height + SAFETY_MARGIN_CM,
    ])
    eligible = []
    for box in boxes:
        box_dims = sorted([box.internal_length, box.internal_width, box.internal_height])
        fits = all(p <= b for p, b in zip(product_dims, box_dims))
        weight_ok = total_weight <= box.max_weight
        if fits and weight_ok:
            box_vol = box.internal_length * box.internal_width * box.internal_height
            product_vol = total_length * total_width * total_height
            wasted = box_vol - product_vol
            eligible.append((box, wasted))

    if not eligible:
        return None
    eligible.sort(key=lambda pair: (pair[1], pair[0].cost))
    return eligible[0][0]
```

Multi-product order ke liye simplest approach: sabhi items ka weight sum karo, aur dimensions ko "sabse bada single item fit hona chahiye" jaise treat karo — ye bhi ek assumption hai jo likhni hogi.

## Step 5: API View (`boxes/views.py`)

```python
from rest_framework.decorators import api_view
from rest_framework.response import Response
from .models import Box, Order
from .services import find_best_box

@api_view(['POST'])
def recommend_box(request):
    order_id = request.data.get('order_id')
    order = Order.objects.get(id=order_id)

    total_weight = sum(i.product.weight * i.quantity for i in order.items.all())
    # simplification: sabse bade item ka dimension use karo
    biggest = max(order.items.all(), key=lambda i: i.product.length * i.product.width * i.product.height)

    boxes = Box.objects.all()
    best = find_best_box(biggest.product.length, biggest.product.width,
                          biggest.product.height, total_weight, boxes)

    if best is None:
        return Response({"error": "No suitable box found"}, status=404)

    return Response({
        "box": best.name,
        "cost": str(best.cost),
        "max_weight": best.max_weight
    })
```

`boxes/urls.py` aur `box_system/urls.py` me route add karo (`path('api/recommend-box/', recommend_box)`).
